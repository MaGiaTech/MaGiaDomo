# Guida per i contributi

Grazie per il tuo interesse nel contribuire a MaGiaDomo! ❤️

## Come contribuire

1. **Fork** il repository su GitHub
2. Crea un branch per la tua funzionalità:
   `git checkout -b feature/nuova-funzionalita`
3. Fai le tue modifiche
4. Esegui i test (se presenti)
5. Fai commit delle modifiche:
   `git commit -m "Aggiunta: nuova funzionalita"`
6. Pusha sul tuo fork:
   `git push origin feature/nuova-funzionalita`
7. Apri una **Pull Request**

## Linee guida

### Codice
- Segui lo stile PHP PSR-12 (se applicabile)
- Usa nomi descrittivi per variabili e funzioni
- Commenta il codice dove necessario

### Commit
- Usa messaggi chiari e descrittivi
- Riferisci gli issue se presenti (es. `Fixes #123`)

### Documentazione
- Aggiorna il README.md se necessario
- Aggiungi commenti per funzioni complesse

## Segnalazione bug

Se trovi un bug, apri un **Issue** con:
- Descrizione del problema
- Passi per riprodurlo
- Comportamento atteso vs reale
- Screenshot (se utile)

## Richiesta di funzionalità

Apri un **Issue** con:
- Descrizione della funzionalità
- Motivo per cui sarebbe utile
- Esempi d'uso (se possibile)
